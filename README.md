# Mobile-sales-Analysis
Developed an interactive Mobile Sales Analysis Dashboard using Power BI to analyze sales, revenue, customer behavior, and brand performance. Cleaned and transformed data with Power Query, created DAX measures and KPIs, and designed dynamic visualizations with slicers, tooltips, and drill-through features to deliver actionable business insights.
